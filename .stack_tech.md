```

  {id}/contratos/              → Contratos do projeto
  {id}/codigosProjeto/         → Códigos de projeto
squads/                        → Squads
users/                         → Usuários / membros
  {id}/changeLog/              → Histórico de alterações por campo
  {id}/statusChangeLog/        → Log de mudanças de status
tickets_global/                → Tickets sincronizados do Jira
  {issueKey}/replanningLog/    → Histórico de replanejamento

ciclos/                        → Ciclos de planejamento
releases/                      → Gestão de releases
operacao_stats/                → Estatísticas do Radar Operação
grupo_atendimento/             → Grupos de atendimento
systems/                       → Sistemas cadastrados
```

## 🚀 Infraestrutura & Deploy

```
┌─────────────────────────────────────────────────┐
│                  Developer Local                │
│  npm run dev  →  Vite Dev Server (localhost)    │
└──────────────────────┬──────────────────────────┘
                       │  npm run build
                       ▼
┌─────────────────────────────────────────────────┐
│              Vite Build (dist/)                 │
│  Tree-shaking · Code splitting · 5651 modules  │
└──────────────────────┬──────────────────────────┘
                       │  firebase deploy --only hosting
                       ▼
┌─────────────────────────────────────────────────┐
│         Firebase Hosting (CDN global)           │
│       https://sgt-renato.web.app                │
└─────────────────────────────────────────────────┘
```

### Processo de Release
```bash
npm run release
# 1. npm version patch   → bump version (ex: 0.1.455 → 0.1.456)
# 2. npm run build       → vite build → dist/
# 3. firebase deploy     → upload para Firebase Hosting
# 4. git push --tags     → tag de versão no repositório
```
